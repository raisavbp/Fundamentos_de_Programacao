3. Algoritmo
   - Um algoritmo em programação é uma sequência de instruções organizadas e lógicas que indica ao computador como resolver um problema ou executar uma tarefa.
   - Pensa assim: uma receita de bolo é um algoritmo! Ela apresenta uma sequência de passos que devemos seguir para chegar a um resultado.
1. Exemplo do dia a dia
Imagine que queremos preparar um café:
1. Pegar uma chávena.
2. Colocar água na máquina.
3. Colocar o café.
4. Ligar a máquina.
5. Esperar o café ficar pronto.
6. Servir.
Isso é um algoritmo: uma sequência de passos para atingir um objetivo.

     # Principais elementos de um algoritmo:
     1. Sequencia:
        As instruções são executadas uma depois da outra.
        Exemplo: receber um nome e apresentar uma saudação.
     3. Decisão( condição):
        O programa escolhe o que fazer dependendo de uma condição.
        Exemplo: se a idade for maior ou igual a 18, permitir a entrada.
     5. Repetição (ciclo):
        O programa repete determinadas instruções.
        Exemplo: percorrer uma lista de 100 clientes e verificar os seus dados.
